# Web Designing Workshop - Assignments

This folder contains the 18 HTML assignments from the Web Designing Workshop-1 document.

## Files
- `assignment-01.html` to `assignment-18.html`: one HTML file for each assignment.
- Assignment 10 refers to optional local media files in a `media/` folder.
- Assignments 17 and 18 submit to the demo handler at the repository root: `submit.php`.

## Run the assignments
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open any assignment HTML file in a web browser, or use the VS Code Live Server extension.
4. For the form submission demo, run the project using a PHP-enabled local server. Opening the HTML files directly will not execute `submit.php`.

All pages include basic HTML structure and viewport metadata. Some assignments also demonstrate accessibility features, responsive overflow, and native browser form validation.
